## Short description

智学工坊 is an open source prototype for personalized AI learning workflows. It combines student profiling, local course-material RAG, seven cooperating learning agents, personalized resource generation, a seven-day study path, tutoring answers, and learning evaluation in a browser-based workspace.

## Maintainer work

I maintain the project by:

- Reviewing and triaging issues.
- Reviewing pull requests for scope, tests, documentation, and privacy risk.
- Maintaining the README, demo guide, roadmap, changelog, and contribution guide.
- Running the Node.js test suite before release.
- Tagging releases and writing release notes.
