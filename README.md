# 智学工坊：个性化资源生成与学习多智能体系统

## 项目简介

本项目是面向《人工智能导论》课程的参赛原型，聚焦“基于大模型的个性化资源生成与学习多智能体系统开发”赛题。系统通过学生画像、知识诊断、多智能体协作、资源生成、学习路径推荐、智能答疑和效果评估，形成完整的个性化学习闭环。

## 核心能力

- 对话式学生画像：从专业、年级、目标、基础、偏好和测试结果构建动态画像。
- 课程资料上传/RAG：支持上传文本型课程资料，自动分块、建索引、检索 Top-K 片段并生成引用。
- 多智能体协作：画像分析、知识诊断、路径规划、资源生成、题库生成、答疑辅导、内容审核 7 个智能体协同工作。
- 个性化资源生成：覆盖讲义、思维导图、练习题、代码案例、PPT/视频脚本 5 类资源。
- 学习路径规划：围绕神经网络基础生成 7 天学习计划。
- 智能答疑：结合课程知识点和学生薄弱点给出解释。
- 学习效果评估：输出掌握度、能力雷达和后续建议，并更新画像。

## 演示流程

1. 选择“神经网络入门”学生样例。
2. 在“课程知识库 / RAG”区域点击“导入示例资料”，或上传 `.txt`、`.md`、`.json`、`.csv` 课程文本资料。
3. 输入检索问题，例如“反向传播为什么需要链式法则？”。
4. 点击“检索并更新流程”，展示 Top-K 片段、来源文件和相关度。
5. 点击“运行多智能体流程”，展示系统如何生成动态学生画像。
6. 展示 7 个智能体协作记录，其中资源生成、答疑和审核会使用 RAG 引用。
7. 展示知识诊断结果、5 类个性化资源、7 天学习路径、智能答疑和学习评估。

## RAG 实现说明

当前版本采用浏览器本地 RAG 原型，适合比赛初赛演示和系统流程说明：

- `src/rag.js` 负责资料解析、文本清洗、知识分块、关键词索引、相关片段检索和带引用回答生成。
- 上传资料不会离开本地浏览器，页面刷新后不会持久保存。
- 检索结果会注入 `runLearningWorkflow`，影响智能答疑、资源来源和内容审核。
- 支持文本型资料：`.txt`、`.md`、`.markdown`、`.json`、`.csv`。
- PDF、PPT、Word 可在后续后端版本中通过文档解析服务接入，再复用同一套 RAG 索引接口。
